TickGlance

Glanceable crypto watchlist and price alerts for Even Realities G2 smart glasses. Live Binance prices for 8 USDT pairs, refreshed every 30 seconds, rendered in the 576×288 glasses display. Read-only by design: no trading, no wallet, no API keys.

How to run it live

TickGlance is a glasses WebView app: its UI is rendered on the G2 display through the Even Hub bridge, not as a web page. In a plain browser the app URL therefore stays blank, by design. To play it in a plain browser instead, use the Play it live button above: it runs the same unmodified app through a JavaScript implementation of the glasses bridge. To run it live, open the Even Hub simulator and load the app from https://tickglance.vercel.app, or install the packaged tickglance.ehpk from the GitHub repository. The screens below are real simulator captures with live Binance data.

Screens

Watchlist: 8 USDT pairs with live prices and 24h direction, one glance.
Coin detail: price, change, and alert controls for the selected pair.
Alert fired: a ±0.25% move alert triggers on a real price move (captured live, 23 Nov 2026).
Manage coins: add or remove pairs from the watchlist, on the glasses.

Demo flow (60 seconds)

  1. Boot to the watchlist: 8 USDT pairs with live Binance prices.
  2. Open a coin detail.
  3. Set a ±0.25% move alert — or a level alert on the next round price levels (new in v0.3.0).
  4. Watch it fire on a real price move.
  5. Manage coins: add or remove a pair.
  6. Clear the alert and exit.

Not done / limits

Developed and tested in the Even Hub simulator; not yet tested on physical G2 hardware. Prices refresh every 30 seconds (polling, not streaming). Read-only by design: no trading, no wallet connection, no API keys. Alerts are local to the app session.
